# Grounding the Agentic Future


Relying on closed AI monoliths means exposing your IP, your data, and your business logic to black boxes you cannot control. Sheep Technologies exists to solve this engineering gap.

We don’t build the model (the engine); we build the Cognitive Middleware that gives it eyes, hands, and safe boundaries. Our mission is to provide the Open-Source Primitives that allow you to decouple Intelligence from Execution. With Sheep, the AI reasons, but you control the infrastructure.

## The Sheep Stack

We provide the foundational toolkit for the next generation of System Architects.

### 1. Crader: The Sovereign Code Intelligence
[https://github.com/sheeptechnologies/crader](https://github.com/sheeptechnologies/crader)

**Build your own Copilot. Keep your IP inside the firewall.**

A production-ready indexer that transforms your repository into a semantic map. It allows agents to navigate dependencies and reason about legacy architecture without ever sending source code to a third-party cloud.

### 2. Crook: The Air-Gapped Data Interface
[https://github.com/sheeptechnologies/crook](https://github.com/sheeptechnologies/crook)

**High-level reasoning on strictly private data.**

The bridge between fluid reasoning and rigid SQL. Crook extracts the schema without touching sensitive values, allowing an LLM to generate precise queries while execution happens locally on your secure infrastructure. (GDPR compliant by design).

### 3. Collie: The Dynamic Skill Manager
[https://github.com/sheeptechnologies/collie](https://github.com/sheeptechnologies/collie)

**Skill Discovery & Fabrication.**

A smart router for tool execution. Collie manages the "muscle memory" of the system, allowing agents to discover existing tools or autonomously generate and register new capabilities on the fly to adapt to unknown tasks.

### 4. Silo: The State Persistence Layer
[https://github.com/sheeptechnologies/silo](https://github.com/sheeptechnologies/silo)

**Memory is Identity.**

Models are ephemeral; Silo provides continuity. It serves as the operational backbone, managing connection pools and persisting the "stream of consciousness" across sessions, turning isolated interactions into long-term workflows.

### 5. Grazer: The Orchestration CLI
[https://github.com/sheeptechnologies/grazer](https://github.com/sheeptechnologies/grazer)

**The Unified Control Plane.**

The global interface (CLI/API) that orchestrates the entire Sheep stack. Grazer abstracts the complexity of the primitives, serving as the bridge between the Architect (you) and the Infrastructure.
